# Hotel Reservation System

## 概要
Ruby on Railsを用いて開発したホテル予約システムです。
ユーザーは会員登録・ログインを行い、ホテルの閲覧や宿泊予約を行うことができます。

## 主な機能

- ユーザー登録
- ログイン・ログアウト
- ホテル一覧表示
- ホテル詳細表示
- 宿泊予約
- マイページ
- 予約履歴確認

## 使用技術

- Ruby
- Ruby on Rails
- SQLite3
- HTML
- CSS
- Bootstrap

## 工夫した点

このアプリでは、利用者側の予約機能だけでなく、管理者側のホテル・部屋・予約管理機能も実装した。単にホテルを表示するだけではなく、会員登録、ログイン、ホテル検索、予約、キャンセル、マイページでの予約確認までを一連の流れとして利用できるようにした。

特に工夫した点は、部屋の在庫管理である。部屋ごとの在庫数だけでなく、日付ごとの在庫を管理できるようにし、予約日によって空き状況を確認できる構成にした。これにより、実際のホテル予約システムに近い仕組みを意識して実装した。

また、管理者側ではホテル情報や部屋情報の追加・編集、予約情報の確認、管理者アカウントの管理を行えるようにした。利用者側と管理者側で画面と権限を分けることで、実際のWebサービスに近い構成を目指した。

さらに、ActiveStorageを用いてホテル画像を登録できるようにし、ホテル一覧や詳細画面で視覚的に情報を確認できるようにした。検索機能では、エリアや条件をもとにホテルを絞り込めるようにし、利用者が目的に合ったホテルを探しやすい設計にした。
